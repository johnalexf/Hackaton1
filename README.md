# T Compra - Tienda Online de Artículos de Tenis

## Enlace de la Página Desplegada

Puedes ver la página en vivo aquí: [https://tcompra.netlify.app/](https://tcompra.netlify.app/)

## Descripción del Proyecto

T Compra es una landing page de e-commerce diseñada para los amantes del tenis. Ofrecemos una amplia variedad de productos, desde raquetas y ropa hasta calzado especializado, permitiendo a los usuarios explorar nuestro catálogo, agregar productos al carrito y ajustar las cantidades según sus necesidades.

## Características Principales

* **Página de Inicio:**
    * Banner dinámico con las ofertas semanales destacadas.
    * Navegación intuitiva a las diferentes categorías de productos.
* **Catálogo de Productos:**
    * Tres categorías principales: Zapatos, Ropa y Raquetas.
    * Visualización detallada de cada producto con imágenes y descripciones.
* **Carrito de Compras:**
    * Funcionalidad para agregar y eliminar productos del carrito.
    * Posibilidad de modificar las cantidades de los productos seleccionados.
    * Visualización clara del total de la compra.
* **Sección "Conócenos":**
    * Declaración de la pasion e historia de la empresa.
* **Sección "Contáctenos":**
    * Formulario de contacto para consultas y comentarios.
    * Información de contacto: ubicación, teléfono, correo electrónico y horario de atención.

## Tecnologías Utilizadas

* HTML5
* CSS3
* JavaScript
* Bootstrap
* SweetAlert

## Instalación y Ejecución Local

1.  **Clonar el Repositorio:**

   ```bash
    git clone [https://tcompra.netlify.app/](https://tcompra.netlify.app/)
    ```


2.  **Abrir con Live Server (Recomendado):**

    * Abre el archivo `index.html` en tu navegador web.
    * Si usas Visual Studio Code, instala la extensión "Live Server" y haz clic derecho en `index.html` para "Open with Live Server".

## Uso

* **Navegación:** Utiliza el menú y los enlaces para explorar las diferentes secciones de la página.
* **Carrito de Compras:** Agrega productos, modifica cantidades y elimina artículos según sea necesario.
* **Formulario de Contacto:** Completa el formulario para enviar consultas o comentarios.
